# handoff

현재 세션의 작업 상태를 다음 세션이 바로 이어받을 수 있도록 **인수인계서** 한 장으로 저장한다. 사용자가 `/clear`로 세션을 비우기 직전에 호출한다.

저장된 인수인계서는 다음 세션이 시작될 때(`SessionStart`, source가 `clear` 또는 `startup`) 이 플러그인의 `inject-handoff.sh` 훅이 자동으로 컨텍스트에 주입한 뒤 파일을 삭제한다(1회용). 주입 시 훅은 원문 앞에 지시문을 덧붙여, 새 세션이 첫 응답 맨 앞에서 인수인계서를 3~5줄로 요약·확인하도록 한다.

## 동작

1. 지금까지의 세션 내용을 아래 6항목 템플릿으로 정리한다. 비어 있는 항목은 "없음"으로 적는다.
2. 작성 시각은 `date '+%Y-%m-%d %H:%M'`로 얻는다.
3. 저장 위치는 **현재 프로젝트의 `.claude/handoff.md`** 다. 경로를 하드코딩하지 말고 아래 명령으로 구한다.

   ```bash
   mkdir -p "${CLAUDE_PROJECT_DIR:-$PWD}/.claude" && echo "${CLAUDE_PROJECT_DIR:-$PWD}/.claude/handoff.md"
   ```

   그 경로에 **덮어쓰기** 저장한다(항상 최신 1장만 유지).
4. 저장 후 사용자에게 한 줄로 보고한다: "인수인계서 저장 완료. 이제 `/clear` 치면 됩니다."

인수인계서 작성과 저장 외의 코드 수정이나 다른 작업은 하지 않는다.

## 작성 원칙

- 추측으로 채우지 말고 이번 세션에서 실제로 다룬 내용만 적는다.
- 다음 세션이 맥락 없이 읽어도 바로 이어갈 수 있도록, 모호한 표현 대신 구체적 파일 경로·결정·다음 행동을 적는다.
- "목표가 끝난 경우"와 "작업 중간인 경우" 둘 다 같은 틀로 적는다. 완료된 경우 "다음 할 일"에는 후속 후보 또는 "없음"을 적는다.
- 민감값(토큰, 비밀번호, 개인정보 원문)은 적지 않는다.
- 모든 내용은 한국어로 작성한다.

## 템플릿

```markdown
# 이전 세션 인수인계서 (작성: <시각>)

## 목표
지금 무슨 문제를 풀고 있었나 / 풀었나 (1~2문장)

## 진행 상황
뭘 했고 어디까지 됐나 (완료면 "완료", 중간이면 어디까지)

## 다음 할 일
미완성이면 이어서 할 것. 완료면 후속 후보 또는 "없음".

## 핵심 파일
이번에 바꾸거나 봐야 할 파일 경로

## 결정·제약·함정
정한 방향, 건드리면 안 되는 것, 주의점

## 남은 리스크
미해결 의문, 검증 안 된 것
```
